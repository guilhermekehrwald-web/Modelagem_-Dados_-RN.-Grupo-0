# Base de Dados

Os dados originais provêm do conjunto **Bitcoin & Ethereum prices (2014-2025)** disponibilizado no Kaggle.

* **Fonte:** https://www.kaggle.com/datasets/kapturovalexander/bitcoin-and-ethereum-prices-from-start-to-2023/data
* **Arquivo necessário:** `ETH-USD (2017-2024).csv`

O notebook baixa o arquivo automaticamente via `kagglehub` caso não esteja presente no diretório local.
